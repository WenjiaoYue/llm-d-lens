## Backend API

Cluster management routes come from `llm_d_bench/cluster/router.py`, `llm_d_bench/cluster/bootstrap/router.py`, and `llm_d_bench/cluster/sdk_discovery.py`.

### List clusters

List Lens-managed clusters and optionally include draft records that have not been finalized yet. The route also computes a `ready` flag per cluster by probing its Kubernetes API reachability.

<Tabs>
  <Tab title="REST API">
    **`GET /api/cluster/clusters`**

    Request: no request body.

    - `includeDrafts` (`boolean`, query, default `false`): include draft cluster records.

    Response: `ClustersResponse` with one `ClusterRecord` per visible cluster.

    ```json
    {
      "items": [
        {
          "id": "cluster-a",
          "name": "Primary cluster",
          "description": "Shared production GPU cluster",
          "createdAt": "2026-09-20T10:15:00Z",
          "ready": true,
          "proxy": {
            "mode": "custom",
            "httpProxy": "http://proxy.example:3128",
            "httpsProxy": "http://proxy.example:3128",
            "noProxy": "127.0.0.1,localhost,.svc"
          },
          "llmDRef": "v0.3.0",
          "llmDBenchmarkRef": "main",
          "llmDRepoPath": "/cache/llm-d/v0.3.0",
          "llmDBenchmarkRepoPath": "/cache/llm-d-benchmark/main",
          "draft": false
        }
      ]
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    import asyncio

    from llm_d_bench.cluster import service

    async def main() -> None:
        clusters = service.list_clusters(include_drafts=True)
        ready_flags = await asyncio.gather(*(service.cluster_is_ready(cluster) for cluster in clusters))
        for cluster, ready in zip(clusters, ready_flags):
            print(cluster.id, cluster.name, ready)

    asyncio.run(main())
    ```
  </Tab>
</Tabs>

### Register a cluster

Register a cluster from an uploaded kubeconfig file. The route accepts multipart form data, stores the cluster record, and returns the new cluster plus any created Lens session id.

<Tabs>
  <Tab title="REST API">
    **`POST /api/cluster/clusters`**

    Request: multipart form-data, not JSON.

    - `name` (`string`, form): cluster display name.
    - `description` (`string`, form, optional): free-form description.
    - `file` (`file`, form): UTF-8 kubeconfig upload.
    - `proxy` (`string`, form, optional): JSON string matching `ProxyConfigDTO`.
    - `llmDRef` (`string`, form, optional): pinned `llm-d` ref.
    - `llmDBenchmarkRef` (`string`, form, optional): pinned `llm-d-benchmark` ref.
    - `gatewayProvider` (`string`, form, optional): shared Gateway provider (`envoy-ai-gateway` | `istio` | `agentgateway` | `gke`).
    - `gatewayPublicUrl` (`string`, form, optional): externally reachable host/IP clients use for the Gateway — Lens adds `http://` + the exposed port + `/v1`. Empty derives it from the exposed port and the cluster node.
    - `gatewayPort` (`integer`, form, optional): NodePort the shared Gateway is exposed on (30000–32767).
    - `gatewayAuthzHost` (`string`, form): the host/IP this cluster uses to reach Lens (required for providers with a Lens address hook: `envoy-ai-gateway`/`istio`/`agentgateway`). Pick from `GET /api/cluster/lens-hosts`; Lens adds its own serving port, and when empty Lens fills in this host's address.
    - `inotifyMaxUserInstances` (`integer`, form, default `8192`): per-uid inotify instance limit Lens applies to every node (`fs.inotify.max_user_instances`). Lift it above kind's 128 default on nodes running many pods.
    - `draft` (`boolean`, form, default `false`): create as draft.

    Example field values:

    ```json
    {
      "name": "Primary cluster",
      "description": "Shared production GPU cluster",
      "file": "<uploaded kubeconfig.yaml UTF-8 file>",
      "proxy": "{"mode":"custom","httpProxy":"http://proxy.example:3128","httpsProxy":"http://proxy.example:3128","noProxy":"127.0.0.1,localhost,.svc"}",
      "llmDRef": "v0.3.0",
      "llmDBenchmarkRef": "main",
      "draft": true
    }
    ```

    Response: `CreateClusterResponse`.

    ```json
    {
      "cluster": {
        "id": "cluster-a",
        "name": "Primary cluster",
        "description": "Shared production GPU cluster",
        "createdAt": "2026-09-23T09:00:00Z",
        "ready": false,
        "proxy": {
          "mode": "custom",
          "httpProxy": "http://proxy.example:3128",
          "httpsProxy": "http://proxy.example:3128",
          "noProxy": "127.0.0.1,localhost,.svc"
        },
        "llmDRef": "v0.3.0",
        "llmDBenchmarkRef": "main",
        "draft": true
      },
      "sessionId": "f4c15c0a-8c1f-4eb7-b4d7-ef83f22c2e9b"
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    from llm_d_bench.cluster import service

    kubeconfig_text = """
    apiVersion: v1
    kind: Config
    clusters: []
    contexts: []
    current-context: ""
    users: []
    """.strip()

    cluster, session = service.create_cluster(
        "Primary cluster",
        "Shared production GPU cluster",
        kubeconfig_text,
        proxy_mode="custom",
        http_proxy="http://proxy.example:3128",
        https_proxy="http://proxy.example:3128",
        no_proxy="127.0.0.1,localhost,.svc",
        llm_d_ref="v0.3.0",
        llm_d_benchmark_ref="main",
        draft=True,
    )

    print(cluster.id, session.id)
    ```
  </Tab>
</Tabs>

### Update a cluster

Patch a cluster's editable settings, including name, description, proxy settings, version pins, and draft status. The kubeconfig itself is not part of this patch contract.

<Tabs>
  <Tab title="REST API">
    **`PATCH /api/cluster/clusters/{cluster_id}`**

    Request body (`ClusterSettingsUpdateRequest`):

    - `name` (`string`, optional)
    - `description` (`string`, optional)
    - `proxy` (`ProxyConfigDTO`, optional)
    - `llmDRef` (`string`, optional)
    - `llmDBenchmarkRef` (`string`, optional)
    - `gatewayProvider` (`string`, optional)
    - `gatewayPort` (`integer`, optional)
    - `gatewayPublicUrl` (`string`, optional): externally reachable Gateway host/IP — Lens adds the exposed port; empty derives it.
    - `gatewayAuthzHost` (`string`): the host/IP this cluster uses to reach Lens (required for providers with a Lens address hook; Lens adds its own serving port; empty fills in this host's address).
    - `inotifyMaxUserInstances` (`integer`, optional): per-uid inotify instance limit applied to every node (default `8192`).
    - `draft` (`boolean`, optional)

    ```json
    {
      "name": "Primary cluster",
      "description": "Shared production GPU cluster",
      "proxy": {
        "mode": "custom",
        "httpProxy": "http://proxy.example:3128",
        "httpsProxy": "http://proxy.example:3128",
        "noProxy": "127.0.0.1,localhost,.svc"
      },
      "llmDRef": "v0.3.0",
      "llmDBenchmarkRef": "main",
      "draft": false
    }
    ```

    Response: `CreateClusterResponse` with the updated record.

    ```json
    {
      "cluster": {
        "id": "cluster-a",
        "name": "Primary cluster",
        "description": "Shared production GPU cluster",
        "createdAt": "2026-09-23T09:00:00Z",
        "ready": true,
        "proxy": {
          "mode": "custom",
          "httpProxy": "http://proxy.example:3128",
          "httpsProxy": "http://proxy.example:3128",
          "noProxy": "127.0.0.1,localhost,.svc"
        },
        "llmDRef": "v0.3.0",
        "llmDBenchmarkRef": "main",
        "draft": false
      },
      "sessionId": null
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    from llm_d_bench.cluster import service

    cluster = service.update_cluster_settings(
        "cluster-a",
        name="Primary cluster",
        description="Shared production GPU cluster",
        proxy_mode="custom",
        http_proxy="http://proxy.example:3128",
        https_proxy="http://proxy.example:3128",
        no_proxy="127.0.0.1,localhost,.svc",
        llm_d_ref="v0.3.0",
        llm_d_benchmark_ref="main",
        gateway_authz_host="10.0.0.5",
        draft=False,
    )
    print(cluster.id, cluster.name)
    ```
  </Tab>
</Tabs>

### Start cluster software downloads

Start downloading the pinned `llm-d` and `llm-d-benchmark` refs for a cluster. The handler schedules background downloads and immediately returns the current status snapshot.

<Tabs>
  <Tab title="REST API">
    **`POST /api/cluster/clusters/{cluster_id}/software-downloads`**

    Request body (`SoftwareDownloadRequest`):

    - `llmDRef` (`string`, optional): `llm-d` ref to download.
    - `llmDBenchmarkRef` (`string`, optional): `llm-d-benchmark` ref to download.

    ```json
    {
      "llmDRef": "v0.2.0",
      "llmDBenchmarkRef": "main"
    }
    ```

    Response: `SoftwareDownloadStatusResponse`.

    ```json
    {
      "llmD": {
        "ref": "v0.2.0",
        "state": "downloading",
        "path": null,
        "error": null
      },
      "llmDBenchmark": {
        "ref": "main",
        "state": "downloading",
        "path": null,
        "error": null
      }
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    import asyncio

    from llm_d_bench.cluster.router import _download_and_record
    from llm_d_bench.cluster import repo_downloads

    async def main() -> None:
        await _download_and_record("cluster-a", "llm-d", "v0.2.0")
        await _download_and_record("cluster-a", "llm-d-benchmark", "main")
        print(repo_downloads.get_status("cluster-a", "llm-d"))
        print(repo_downloads.get_status("cluster-a", "llm-d-benchmark"))

    asyncio.run(main())
    ```
  </Tab>

### Read a planning-discovery resource

Read one allowlisted planning-discovery resource for an active cluster session. This endpoint is intentionally limited to fixed `kubectl` reads and returns `{"result": null}` when a read fails or yields unusable JSON.

<Tabs>
  <Tab title="REST API">
    **`GET /api/cluster/sessions/{session_id}/planning-discovery/{resource}`**

    Request: no request body.

    - `session_id` (`string`, path): active cluster session id.
    - `resource` (`string`, path): one of `version`, `nodes`, `deviceclasses`, or `resourceslices`.

    Response: wrapper object with a `result` key.

    ```json
    {
      "result": {
        "items": []
      }
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    import asyncio
    import json

    from llm_d_bench.cluster import sessions
    from llm_d_bench.utils.kubernetes import run_kubectl

    async def main() -> None:
        session = sessions.require_active_session("f4c15c0a-8c1f-4eb7-b4d7-ef83f22c2e9b")
        result = await run_kubectl(["get", "nodes", "-o", "json"], timeout=10, cluster_id=session.id)
        payload = json.loads(result.stdout) if result.ok else None
        print({"result": payload if isinstance(payload, dict) else None})

    asyncio.run(main())
    ```
  </Tab>

### Discover bootstrap SSH host keys

Read the SSH host key from each target without authenticating or sending credentials. Host specifications and IP ranges are expanded server-side, so every response item identifies one exact `host:port`. Compare these SHA-256 fingerprints against a trusted source before confirming them in the UI.

<Tabs>
  <Tab title="REST API">
    **`POST /api/cluster/bootstrap/host-keys`**

    ```json
    {
      "nodes": [{ "host": "10.0.0.10-12", "port": 22 }]
    }
    ```

    Each response item contains `host`, `port`, `algorithm`, and `fingerprint`; unreachable hosts contain an `error` instead.

    ```json
    {
      "items": [
        { "host": "10.0.0.10", "port": 22, "algorithm": "ssh-ed25519", "fingerprint": "SHA256:AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA" },
        { "host": "10.0.0.11", "port": 22, "algorithm": "ssh-ed25519", "fingerprint": "SHA256:BBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBB" },
        { "host": "10.0.0.12", "port": 22, "error": "Connection timed out" }
      ]
    }
    ```
  </Tab>
</Tabs>

### Run bootstrap preflight checks

Run Kubespray bootstrap preflight checks against one or more target machines. The response reports per-node state plus the individual checks that passed, failed, or were skipped.

<Tabs>

    Request body (`BootstrapPreflightRequest`):

    - `nodes` (`BootstrapNodeInput[]`): rows of host, SSH, and role information.
    - `hostKeys` (`BootstrapHostKeyPin[]`): the exact confirmed fingerprint for every expanded `host:port`.

    ```json
    {
      "nodes": [
        {
          "host": "10.0.0.1",
          "port": 22,
          "roles": [
            "control-plane"
          ],
          "username": "root"
        },
        {
          "host": "10.0.0.2",
          "port": 22,
          "roles": [
            "worker"
          ],
          "username": "root"
        }
      ],
      "hostKeys": [
        { "host": "10.0.0.1", "port": 22, "fingerprint": "SHA256:AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA" },
        { "host": "10.0.0.2", "port": 22, "fingerprint": "SHA256:BBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBB" }
      ]
    }
    ```

    Response: `BootstrapPreflightResponse`.

    ```json
    {
      "items": [
        {
          "host": "10.0.0.1",
          "roles": [
            "control-plane"
          ],
          "state": "passed",
          "checks": [
            {
              "id": "ssh",
              "label": "SSH connectivity",
              "status": "passed",
              "detail": "reachable"
            },
            {
              "id": "sudo",
              "label": "Passwordless sudo",
              "status": "passed"
            }
          ]
        },
        {
          "host": "10.0.0.2",
          "roles": [
            "worker"
          ],
          "state": "passed",
          "checks": [
            {
              "id": "ssh",
              "label": "SSH connectivity",
              "status": "passed",
              "detail": "reachable"
            }
          ]
        }
      ],

    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    import asyncio

    from llm_d_bench.cluster.bootstrap.dto import BootstrapHostKeyPin, BootstrapNodeInput
    from llm_d_bench.cluster.bootstrap.service import run_preflight_check

    async def main() -> None:
      pins = [
        BootstrapHostKeyPin(host="10.0.0.1", port=22, fingerprint="SHA256:AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA"),
        BootstrapHostKeyPin(host="10.0.0.2", port=22, fingerprint="SHA256:BBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBB"),
      ]
        nodes = await run_preflight_check([
            BootstrapNodeInput(host="10.0.0.1", roles=["control-plane"]),
            BootstrapNodeInput(host="10.0.0.2", roles=["worker"]),
      ], pins)
        for node in nodes:
            print(node.host, node.preflight_state)

    asyncio.run(main())
    ```

### Start a bootstrap job

Start a long-running Kubespray-based cluster bootstrap job after preflight succeeds. The response returns the bootstrap job id immediately while the real provisioning continues in the background.

<Tabs>
  <Tab title="REST API">
    **`POST /api/cluster/bootstrap`**

    Request body (`BootstrapCreateRequest`):

    - `nodes` (`BootstrapNodeInput[]`): the nodes to provision.
    - `hostKeys` (`BootstrapHostKeyPin[]`): the exact confirmed fingerprint for every expanded `host:port`.
    - `proxy` (`BootstrapProxyConfig`, optional): target-node proxy configuration.

    ```json
    {
      "nodes": [
        {
          "host": "10.0.0.1",
          "port": 22,
          "roles": [
            "control-plane"
          ],
          "username": "root"
        },
        {
          "host": "10.0.0.2",
          "port": 22,
          "roles": [
            "worker"
          ],
          "username": "root"
        }
      ],
      "hostKeys": [
        { "host": "10.0.0.1", "port": 22, "fingerprint": "SHA256:AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA" },
        { "host": "10.0.0.2", "port": 22, "fingerprint": "SHA256:BBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBB" }
      ],
      "proxy": {
        "mode": "custom",
        "httpProxy": "http://proxy.example:3128",
        "httpsProxy": "http://proxy.example:3128",
        "noProxy": "127.0.0.1,localhost,.svc"
      }
    }
    ```

    Response: `BootstrapCreateResponse`.

    ```json
    {
      "bootstrapId": "bootstrap-5b7fd3a81290"
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    import asyncio

    from llm_d_bench.cluster.bootstrap.dto import BootstrapHostKeyPin, BootstrapNodeInput, BootstrapProxyConfig
    from llm_d_bench.cluster.bootstrap import service

    async def main() -> None:
      pins = [
        BootstrapHostKeyPin(host="10.0.0.1", port=22, fingerprint="SHA256:AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA"),
        BootstrapHostKeyPin(host="10.0.0.2", port=22, fingerprint="SHA256:BBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBBB"),
      ]
        job = service.create_job(
            [
                BootstrapNodeInput(host="10.0.0.1", roles=["control-plane"]),
                BootstrapNodeInput(host="10.0.0.2", roles=["worker"]),
            ],
            pins,
            proxy=BootstrapProxyConfig(
                mode="custom",
                httpProxy="http://proxy.example:3128",
                httpsProxy="http://proxy.example:3128",
                noProxy="127.0.0.1,localhost,.svc",
            ),
        )
        await service.run_bootstrap_job(job.id)
        print(job.id)
    ```

### Get bootstrap status

Get the current status of a bootstrap job. When the job first reaches `succeeded`, this response can also carry the one-time kubeconfig handoff.

<Tabs>
  <Tab title="REST API">
    **`GET /api/cluster/bootstrap/{bootstrap_id}`**

    Request: no request body.

    - `bootstrap_id` (`string`, path): bootstrap job id.

    Response: `BootstrapStatusResponse`.

    ```json
    {
      "id": "bootstrap-5b7fd3a81290",
      "phase": "succeeded",
      "logTail": "PLAY [all]
ok: [10-0-0-1]",
      "error": null,
      "kubeconfig": "apiVersion: v1
kind: Config
clusters: []
contexts: []
users: []
"
    }
    ```
  </Tab>
  <Tab title="Python API">
    ```python
    from llm_d_bench.cluster.bootstrap import service

    job = service.get_job("bootstrap-5b7fd3a81290")
    kubeconfig = service.consume_kubeconfig(job.id) if job.phase == "succeeded" else None
    print(job.phase, kubeconfig)
    ```
  </Tab>
</Tabs>

### Cancel a bootstrap job

Cancel a running bootstrap job so it stops provisioning and does not continue. This endpoint returns immediately once cancellation has been requested.

<Tabs>
  <Tab title="REST API">
    **`POST /api/cluster/bootstrap/{bootstrap_id}/cancel`**

    Request: no request body.

    - `bootstrap_id` (`string`, path): bootstrap job id.

    Response: `204 No Content`. This endpoint does not return a JSON body.
  </Tab>
  <Tab title="Python API">
    ```python
    from llm_d_bench.cluster.bootstrap import service

    service.cancel_job("bootstrap-5b7fd3a81290")
    ```
  </Tab>
</Tabs>
