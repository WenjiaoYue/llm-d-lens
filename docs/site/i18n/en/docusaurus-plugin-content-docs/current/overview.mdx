Lens is a web console for running large language models on Kubernetes with
[llm-d](https://llm-d.ai/). Use it to deploy a model, publish an API endpoint,
and measure its performance.

## First time using Lens?

Follow [Quickstart](/quickstart) to install Lens and get your first model response.
The normal path is:

1. [Add a cluster](/user-guide/clusters).
2. [Prepare storage](/user-guide/storage) and [download model weights](/user-guide/model-cache).
3. [Deploy a model](/user-guide/model-market) and wait for it to be ready.
4. [Publish a service and create an API key](/tutorials/publish-a-model-service).
5. [Run an evaluation](/tutorials/evaluate-a-deployment).

## Get help

For a failed operation, read its error message and logs, then check
[Troubleshooting](/troubleshooting). If a resource or action is missing, ask an
administrator to check your permissions.

For automation, use the [API reference](/api-reference). Implementation details
are in [Architecture](/architecture), separate from the operating instructions.
