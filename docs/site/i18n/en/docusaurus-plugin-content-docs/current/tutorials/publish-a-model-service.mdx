---
title: Publish a model service
description: Publish a ready deployment and send an authenticated model request.
---

Start with a [ready llm-d deployment](/tutorials/bootstrap-and-deploy).
Use an account with model-service management access to publish it.

## 1. Create a public model name

1. Open **Model services** and click **Add model service**.
2. Select the deployment's **Cluster**.
3. In **Model name (user-facing)**, enter a name such as `qwen-demo`.
4. Click **Create**.

## 2. Attach the deployment

1. Click **Add model server**.
2. Select **Cluster**, then the new **Model service**, then the ready **Deployment**.
3. Check **Derived target (from the deployment)** and click **Add provider**.
4. In **Service flow**, inspect the status dots for the service.

If there is no eligible deployment, confirm it is in the same cluster and was
created with an llm-d Guide that provides an InferencePool.

## 3. Check the gateway

1. Find the cluster's **Gateway** node in **Service flow**.
2. If it is not installed, open its menu and click **Install**.
3. If its settings need to be reapplied, click **Reconcile**.
4. Read the operation log and wait for the gateway and service components to become healthy.

If the address is wrong, update it under **Clusters → Edit cluster → Gateway host/IP**.
For a failed installation, see [Troubleshooting](/troubleshooting).

## 4. Create an API key

1. Open **API keys → New key**.
2. Enter a key name, such as `first-call`, and click **Create**.
3. Click **Copy**, store the full key, then click **I saved it**.

The full key is shown only once. Do not put it in source code or share it with another user.

## 5. Send a request

1. Open **My services** and find `qwen-demo`.
2. Click **cURL**, then **Copy** beside the chat request example.
3. Paste it into your terminal. Replace `lens-mk-...` with your key, keeping the other headers and URL.
4. Run the request and confirm it returns a model reply.

You can now [benchmark this service](/tutorials/evaluate-a-deployment).
For application code, use the examples in [Integrations](/integrations).
