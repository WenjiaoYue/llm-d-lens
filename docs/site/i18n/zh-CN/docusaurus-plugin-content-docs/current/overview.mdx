Lens 是一个基于 [llm-d](https://llm-d.ai/) 在 Kubernetes 上运行大模型的网页控制台。
你可以用它部署模型、发布 API 端点并测量性能。

## 第一次使用

按[快速开始](/quickstart)安装 Lens 并获得第一条模型回复。通常按以下顺序操作：

1. [添加集群](/user-guide/clusters)。
2. [准备存储](/user-guide/storage)并[下载模型权重](/user-guide/model-cache)。
3. [部署模型](/user-guide/model-market)，等待就绪。
4. [发布服务并创建 API 密钥](/tutorials/publish-a-model-service)。
5. [运行评估](/tutorials/evaluate-a-deployment)。

## 遇到问题

操作失败时，先查看错误提示和日志，再查[故障排查](/troubleshooting)。
看不到资源或按钮时，请管理员检查权限。

自动化调用见 [API 参考](/api-reference)。实现原理放在[架构文档](/architecture)，
不需要先读懂架构才能按操作手册使用。
