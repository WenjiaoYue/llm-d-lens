---
title: 外部服务提供方
description: 配置 Lens 可选 AI 功能所使用的、兼容 OpenAI 或 Anthropic 的 AI 提供方。
---

添加外部 AI 提供方后，即可在 Lens 的 AI 功能中选择它。
先准备好 API 基础地址、模型名称和 API 密钥。
用于 **Lens Assistant** 时，请选择兼容 OpenAI 的提供方。

## 添加提供方

1. 在**外部服务提供方**页面，点击**添加提供方**。
2. 填写 **Name（名称）**、选择 **API type（API 类型）**，从提供方的 API 文档复制 **Base URL（基础地址）**和 **Model（模型名称）**。
3. 将密钥填入 **API key**，不要放进 URL。地址必须是公开的 HTTPS 地址，且不能带查询参数或片段标识；不支持私有网络地址。
4. 首次测试保持 **Timeout（超时）**的初始值，点击 **Test connection（测试连接）**。
5. 点击 **Add provider（添加提供方）**，确认列表中出现新条目。

连接测试失败时仍可保存，但使用前应先修正地址、模型名称或密钥，再次测试。

## 搜索和筛选提供方

1. 使用**搜索名称、基础 URL 或模型……**来筛选表格。
2. 打开**类型**来按提供方类型筛选。
3. 点击**清除筛选条件**来移除当前生效的筛选。
4. 在**外部服务提供方**表格中查看筛选后的结果。

## 测试一个已保存的提供方

1. 在**外部服务提供方**表格中找到该提供方。
2. 在**测试**列中，点击**测试**。
3. 等待同一行中的状态图标更新，如果需要完整的结果消息，
   将鼠标悬停在上面即可。

## 编辑提供方

1. 在提供方所在行点击 **Edit（编辑）**。
2. 在**编辑 AI 提供方**中，更新你需要的字段。
3. 如果**API 密钥**那一行提示密钥已经保存，当你想保留现有密钥时，
   将该字段留空。
4. 可选地点击**测试连接**来检查修改后的设置。
5. 点击**保存更改**。

## 删除提供方

1. 在提供方所在行点击 **Delete（删除）**。
2. 在**删除 AI 提供方**中，查看警告文本。
3. 点击**删除提供方**。
